# Data Matrix

[Back to the index](../index.md)

- **Name:** `data-matrix` — also `datamatrix`, `dm`, `ecc200`
- **Accepts:** any byte string, up to 1556 bytes of ASCII or 778 digit pairs
- **Payload:** `ScanMePHP`
- **Modules:** 16 × 16
