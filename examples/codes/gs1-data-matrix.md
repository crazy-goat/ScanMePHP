# GS1 Data Matrix

[Back to the index](../index.md)

- **Name:** `gs1-data-matrix` — also `gs1-datamatrix`, `gs1dm`
- **Accepts:** GS1 element strings, as (AI)data — e.g. (01)09501101020917(10)LOT0001
- **Payload:** `(01)09501101020917(10)LOT0001`
- **Modules:** 18 × 18
