# QR Code

[Back to the index](../index.md)

- **Name:** `qrcode` — also `qr`
- **Accepts:** any byte string, up to 2953 bytes at error correction level L
- **Payload:** `https://scanmephp.dev`
- **Modules:** 25 × 25
- **Error correction:** L, M, Q, H
